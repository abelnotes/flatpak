AbelNotes for Linux

Works on any distribution. Updates arrive through your software center, like every other app.

Install AbelNotes
Opens in GNOME Software, KDE Discover or Mint's Software Manager · abelnotes.app

How it works

  1. 1
    Click Install AbelNotes.

    Your browser downloads a small .flatpakref file. Open it.

  2. 2
    Confirm in your software center.

    It adds the signed AbelNotes repository and installs the app. The runtime comes from Flathub.

  3. 3
    That's it.

    New versions show up in your usual updates. Nothing else to do.

From a terminal

flatpak install --user @SITE_URL@/abelnotes.flatpakref

Fedora, Linux Mint and Pop!_OS have Flatpak already. On Ubuntu, first run sudo apt install flatpak gnome-software-plugin-flatpak and log out and back in.
