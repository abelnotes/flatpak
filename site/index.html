AbelNotes for Linux

Flatpak · version @VERSION@ · updates arrive on their own

Install

Opens in GNOME Software, KDE Discover or the Mint Software Manager. The AbelNotes repository is added for you, so future updates show up there like any other app.

Install AbelNotes

From a terminal

flatpak install --user @SITE_URL@/abelnotes.flatpakref

Fedora, Linux Mint and Pop!_OS have Flatpak already. On Ubuntu: sudo apt install flatpak gnome-software-plugin-flatpak, then log out and back in; the install button then opens in Software.
